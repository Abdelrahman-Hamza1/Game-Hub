About

Small games for a quick break or a night in with friends.

Game Night is a collection of small games that run in your browser. There's nothing to install and no account to make. New games get added over time.

Solo

Play on your own. Scores and progress stay saved in this browser.

Same screen

Pass one phone or share one keyboard and take turns.

Online rooms

Create a room, send friends the 4-letter code, and pick games together from the lobby.

How rooms work

  • The host's browser runs the room. Players connect directly to the host (peer-to-peer), so there's no game server.
  • If the host leaves, the room closes. Anyone can start a new one in a second.
  • Rooms hold up to 8 players. Each game says how many players it needs.
  • Some networks block direct connections, like certain school or office Wi-Fi. If joining keeps failing, try mobile data.

Privacy

Game Night has no accounts and no tracking. Your name, scores, and settings are saved only in your own browser. In a room, your name and game moves go straight to the other players. A public matchmaking service (PeerJS) introduces browsers to each other, but game data doesn't go through it.
