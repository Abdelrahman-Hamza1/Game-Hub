# Short Rope

A co-op climbing game about real rope work. One friend leads, clips and climbs one limb at a time; the other feeds slack and catches the falls. The rope, the quickdraws and the fall physics are simulated.

**Play:** https://abdelrahman-hamza1.github.io/Game-Hub/games/short-rope/ (part of Game Night)

- **Solo:** you lead, a bot belays
- **Two players, one computer:** mouse climbs, arrow keys belay
- **Online:** make a Game Night room, share the code, up to 4 friends take turns leading and belaying

Runs entirely in the browser and on GitHub Pages: no server. Online play goes through Game Night rooms (peer-to-peer over WebRTC).
